# SubsetLab — NFA to DFA

CSET302 Automata Theory simulator. Converts a user-defined NFA to an equivalent DFA with subset construction, step-by-step tables, graphs, and dual string testing.

## Scripts

```bash
npm install
npm test
npm run dev
```
